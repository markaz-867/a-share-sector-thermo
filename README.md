# A股板块位置温度计

每交易日自动更新的板块位置看板：**56 个标的**（中证/国证行业指数 + 主题 ETF），用**双窗口位置百分位**回答一个问题 —— 这个板块现在到底在近 3 年 / 近 5 年的什么位置。

在线查看：https://markaz-867.github.io/a-share-sector-thermo/index.html

## 三个视图

同一份数据，三种看法，顶部 Tab 切换：

| 视图 | 用途 | 关键交互 |
|---|---|---|
| **矩阵** | 找机会。横轴位置、纵轴趋势，四象限一眼分开"底部反转"与"阴跌寻底" | 纵轴可切「近1年超额 / 轮动60日 / 轮动20日」 |
| **排行** | 排序比较。全部标的按位置从低到高排列，黄色虚线是沪深300 基准 | 点击条形看明细 |
| **表格** | 看全字段。9 个分组默认折叠（标题栏带组内均值），点击展开 | 「全部展开 / 全部收起」 |

顶部还有**状态筛选器**（阴跌寻底 / 低位磨底 / 底部反转 / 高位强势 / 高位走弱 …），带实时计数，筛选结果同时作用于三个视图。

## 它解决什么问题

宽基指数报表（沪深300 / 创业板指 / 科创50）只能告诉你"大盘在哪"，看不见内部分化。同一个时点：

- 沪深300 在 70% 位置（偏高）
- 通信 ETF 在 76.7%，近 1 年 **+106.6%**
- 全指信息（科技整体）只有 15.6%
- 中证白酒 4.0%，近 1 年 **−35%**

算力在天上、科技整体在地板、消费在阴跌 —— 这三层信息，任何宽基指数都给不了。

## 核心指标

| 指标 | 定义 | 怎么看 |
|---|---|---|
| **位置百分位** | `(现价 − 窗口最低) / (窗口最高 − 窗口最低) × 100` | 0% = 窗口内最低点，100% = 最高点 |
| **双窗口** | 近 3 年（灵敏，抓轮动）+ 近 5 年（稳健，防噪音） | 3 年明显高于 5 年 = 从深坑爬出 |
| **抬升度** | 3 年位置 − 5 年位置 | 正值 = 底部在抬高 |
| **超额 1 年** | 标的近 1 年收益 − 沪深300 收益 | 是否已经跑赢/跑输大盘 |
| **轮动速度** | 当前位置% − N 个交易日前的位置%（均按当时可见的滚动窗口重算） | **正 = 位置在往上爬，负 = 在往下掉。** 20 日看短期方向，60 日看中期趋势 |
| **组内排名** | 该标的在自己分组内按 5 年位置的排名 | 操作层面常比绝对位置更直接 |

### 轮动速度是这份表最值钱的一栏

位置百分位是**静态快照**，看不出方向。同样在 15% 位置，一个可能是从 5% 爬上来的（转机），一个可能是从 30% 掉下来的（还没跌完）—— 单看位置完全分不出来。

实测两个典型：

- **煤炭：20 日 +19.7、60 日 −13.4** → 短期急拉，但中期仍在下行，属反弹而非反转
- **港股创新药：20 日 +9.6、60 日 +30.6** → 短中期同向向上，是真趋势

**两个周期同号 = 趋势稳定；20 日为正、60 日为负 = 典型的下跌中继反弹。**

### 状态判定（关键：区分"周期低位"和"结构性衰退"）

宽基的"逐年低点买入"暗含一个假设：长期向上，跌了会回来。**板块没有这个保证**。实测反例：某行业指数从 2015 年底 993 点跌到今天 907 点，11 年负收益 —— 机械照搬会连买 11 年。

所以在位置之上叠了趋势确认：

| 状态 | 条件 | 含义 |
|---|---|---|
| 阴跌寻底 | 5 年位置 ≤20%，抬升度 <15，超额 1 年 <−10% | 低，但还在往下走，慎抄底 |
| 低位磨底 | 5 年位置 ≤20%，抬升度 ≥15 | 没破前低，但也没起色 |
| 低位企稳 / **底部反转** | 5 年位置 ≤20% 且超额已转正（反转还需底部抬升） | 跌不动了，最稀缺的一档 |
| 偏高 / **高位强势** | 位置 >60% 且超额 1 年 >+20% | 位置高但仍在跑赢，趋势未破 |
| 高位走弱 | 位置 >60% 且超额 1 年 <−10% | 位置高但已跑输，注意见顶 |

**做三重确认再动手**：位置低 + 底部抬升 + 超额转正 + 轮动速度转正。四个条件里位置只占其一 —— 位置低是最弱的那个信号。

## 数据源与技术取舍

| 数据源 | 用途 | 说明 |
|---|---|---|
| 腾讯 `web.ifzq.gtimg.cn/appstock/app/fqkline/get` | 主源 | 中证/国证指数、ETF 均支持 |
| 新浪 `money.finance.sina.com.cn/.../CN_MarketData.getKLineData` | 备用 | 腾讯失败时自动切换 |

**为什么不用东方财富板块（BKxxxx）**：东财板块分类最全（496 行业 + 504 概念），但在 GitHub Actions 云端 IP 被封，无法自动更新。中证/国证指数 + 主题 ETF 在腾讯/新浪源 100% 可用，牺牲一点覆盖面换取**每天自动跑**。

**ETF 的复权处理**：腾讯源对 ETF 的"前复权"只给 641 根（2.6 年），"不复权"给 1301 根（5.2 年）。因此 ETF 走不复权 + 分红跳空修正 —— 单日跌幅 >10% 且同期基准未跌，判定为除息并做后向调整。

## 自动更新

`.github/workflows/daily.yml`，周一至周五北京时间 **08:41 / 12:21 / 15:51 / 18:41 / 21:21** 各跑一次（GitHub 定时任务有排队延迟，多设几个错峰点保证当天一定刷新）。用 Actions 自带 `GITHUB_TOKEN` 推送，不依赖任何个人凭证。

## 本地运行

```bash

```

纯 Python 标准库，无需安装任何依赖。
